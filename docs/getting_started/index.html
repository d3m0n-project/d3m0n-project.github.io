Getting Started with d3m0n OS

You have a blank d3m0n device and want to see it boot. Install d3m0n OS on a microSD card, put the card in the device, and power it on.

What you need: a d3m0n C1 device, a microSD card, a card reader for your computer, and a computer with internet access. The OS is distributed as a bootable SD card image; you do not need to compile it for a first boot.

1. Download the OS image

  1. Open the latest d3m0n OS release.
  2. Download the release's .img image to your computer. If it is provided compressed, extract it first so the image file is ready to flash.

2. Flash the microSD card

  1. Download and install balenaEtcher.
  2. Insert the microSD card into your computer. Copy any files you want to keep from it first; flashing erases the selected card.
  3. In Etcher, choose Flash from file and select the d3m0n OS .img.
  4. Choose the microSD card as the target, check that you selected the right removable drive, then choose Flash.
  5. Wait for Etcher to finish writing and verifying the image, then safely eject the card.

3. Boot your device

  1. With the device powered off, insert the flashed microSD card into its card slot.
  2. Connect the device's display and power, then switch it on. The firmware and system files are now on the card, so the device can boot from it.
  3. Wait for startup to finish. If it does not boot, power off and check that the card is fully seated and that Etcher completed verification; then flash the image again or try another supported microSD card.

4. Build and run an app

Once d3m0n OS is running, you can build native applications with the d3c compiler and SDK. The Academy walks through installing d3c, creating a project, compiling a .d3m0n executable, and copying it into the device's /apps directory.

Learn to build d3m0n apps in the Academy

Build the OS yourself

For developers who want to build an image from source, follow the d3m0n_os repository instructions. The source build currently targets Linux and creates an SD image with make export.
